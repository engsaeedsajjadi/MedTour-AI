# بخش ۲۴ — ارکستراسیون عامل‌های اداری

## محدوده اجرا
سه عامل `administrative_receptionist`، `travel_coordinator` و `knowledge_assistant` با گردش‌کارهای از پیش‌تعریف‌شده برای فارسی، عربی، انگلیسی، پشتو و دری ساخته شده‌اند. هر Tenant عامل‌های خود را به‌صورت مستقل و خاموش در ابتدا دریافت می‌کند.

### ایمنی
هیچ ورودی متن آزاد، شناسه بیمار، سند پزشکی یا URL دلخواه پذیرفته نمی‌شود. تنها ابزار داخلی، خواندن شناسه چند مقاله دارای وضعیت approved از همان Tenant است. متن مقالات یا پرونده‌ها به مدل منتقل نمی‌شود. خروجی‌ها هرگز خودکار ارسال یا برای تصمیم‌گیری درمانی، مالی و رزرو استفاده نمی‌شوند. تأیید مدیر صرفاً به معنی پذیرش داخلی است؛ سازنده نمی‌تواند خروجی خودش را تأیید کند.

## دو حالت
- `deterministic_demo`: قالب‌های ثابت غیرهوشمند، بدون تماس شبکه‌ای، مخصوص توسعه و تست.
- `approved_provider`: تماس با آداپتور OpenAI-compatible موجود فقط پس از تنظیم میزبان HTTPS مجاز، مدل و کلید و سیاست opt-in. تنها درخواست غیرشخصی و ثابت ارسال می‌شود و خروجی به بررسی انسانی می‌رود. این تنظیمات مجوز حقوقی مستقل یا پردازش PHI نیستند.

## اجرا و مدیریت
پس از دریافت و اجرای Migration `a24f703c9b62`، در `http://localhost:3000/ai-orchestration` عامل را فعال و با حساب operator درخواست ثبت کنید؛ مدیر متفاوت از سازنده می‌تواند خروجی را رد یا صرفاً برای استفاده داخلی قبول کند.

```powershell
git pull origin main
docker compose up -d --build
docker compose exec api alembic upgrade head
```

APIهای `/api/v1/ai-orchestration/catalog`، `/agents/{agent_key}`، `/runs`، `/runs/{id}/review` و `/runs/{id}/events` به‌ترتیب برای مشاهده سیاست‌ها، کنترل مدیر، پیش‌نویس، بررسی و حسابرسی قابل استفاده‌اند. جداول `ai_agent_policies`، `ai_orchestration_runs`، `ai_orchestration_events` با tenant isolation و idempotency ایجاد شده‌اند.

## دروازه‌های تجاری
نسخه حاضر فقط هماهنگی اداری Alpha است. احراز قانونی قرارداد مدل، MFA/RLS، حفاظت کامل از داده پزشکی، ارزیابی تخصصی RAG، پایش واقعی هزینه توکن، کنترل شبکه و retry/backoff صف توزیع‌شده، ارزیابی ترجمه تخصصی و STT/TTS هنوز نیازمند پیاده‌سازی و تأیید مستقل هستند. گفتار مربوط به بخش ۲۵ است؛ هیچ بیمار واقعی یا درمان خودکار پشتیبانی نمی‌شود.
