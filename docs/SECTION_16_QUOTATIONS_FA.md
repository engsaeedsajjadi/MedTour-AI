# بخش ۱۶ — پیش‌فاکتورها و برآورد هزینه

**محدوده:** داده ساختگی Alpha؛ تأیید داخلی مالی، نه صورتحساب بیمارستان یا پرداخت واقعی.

در کنار API قدیمی پیش‌فاکتور، مسیرهای `/api/v1/quotation-versions` توسعه یافت. هر نسخه دارای snapshot تغییرناپذیر ردیف‌های قیمت‌گذاری شامل شناسه منبع، کد خدمت، مبلغ واحد به واحد جزء ارز، تعداد، جمع ردیف، منبع استعلام محلی و زمان اعتبار است. جمع با حساب صحیح integer و سقف `10^15` محاسبه می‌شود. درون یک نسخه تنها یک ارز مجاز است؛ FX خودکار یا نرخ ساختگی ممنوع است. قیمت منقضی اجازه ساخت نسخه یا تأیید ندارد. نسخه جدید، نسخه قبلی تأییدنشده را `superseded` می‌کند و نسخه تأییدشده قابل تغییر نیست.

ثبت تأیید مدیر تنها برای آخرین نسخه با جمع محاسبه‌شده معتبر و مرجع اداری صورت می‌گیرد و Audit و CaseTimeline اضافه می‌کند. مسیر قدیمی تأیید برای پیش‌فاکتورهای نسخه‌دار مسدود است. خروجی PDF ساده انگلیسی فاقد PHI فقط از snapshot تأییدشده ایجاد می‌شود؛ PDF معادل سند رسمی بیمارستان نیست. UI فارسی در `/quotations` برای ساخت پایه، انتخاب قیمت و تأیید مدیر تهیه شده است. دریافت باینری PDF از API احرازشده انجام می‌شود و دانلود مستقیم در UI فعلاً رابط نیازمند توسعه مجزا است.

جدول `quote_versions` با Migration `a16ef029c5d1` به مخزن اضافه شد. تست‌های `test_section_16_quotations.py` محاسبه، نسخه‌بندی، PDF، نقش مدیر، مانع API قدیمی، Tenant isolation، رضایت و ممنوعیت ارز ترکیبی را بررسی می‌کنند.

**Production gate:** مالیات/بیمه/تخفیف/تقسیط، استعلام تأییدشده قیمت خارجی، سیاست تاریخ انقضای نرخ ارز، صدور سند قانونی رسمی، اسناد چندزبانه PDF، RLS، MFA، بازبینی حقوقی و امنیت PHI هنوز نیازمند توسعه و تأیید مستقل است.
