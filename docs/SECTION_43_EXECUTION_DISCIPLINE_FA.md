# بخش ۴۳ — Execution Discipline

## خروجی ثبت‌شده
این بخش اکنون یک ابزار کنترل فرایند دارد: `scripts/section43_change_gate.py` و سیاست ماشین‌خوان `docs/section43_change_control.json`. از تغییر نرم‌افزار تا پذیرشِ آماده بررسی، هفت مدرک لازم است: بازبینی محدوده، تست Backend، Build Frontend، بازبینی Migration، امنیت Tenant، حریم خصوصی و برنامه Rollback. هیچ‌کدام از این مدارک در این PR به‌عنوان انجام‌شده ثبت نشده‌اند.

## مقررات
1. تمام داده‌های تست مصنوعی و فاقد اطلاعات بیمار واقعی باشند.
2. ویژگی موجود بدون بازبینی و آزمون حذف نشود.
3. PRهای باز، ترتیب Alembic و تعارض‌ها پیش از ادغام بازبینی شوند.
4. هر نتیجه PASS باید شناسه قابل ردیابی و مستقل داشته باشد.
5. اجازه استقرار واقعی و استفاده از اطلاعات درمانی تنها با فرایند تأیید امنیت، بالین و حقوقی مستقل صادر شود.
6. گزارش «کد ثبت شد» نباید با «کد تست شد»، «کد ادغام شد» یا «آماده Production است» اشتباه گرفته شود.

## تست
```powershell
git fetch origin
git switch feature/section-43-execution-discipline
cd backend
python -m pytest -q tests/test_section_43_change_control.py
cd ..
python scripts/section43_change_gate.py
```
آخرین فرمان عمداً با exit code 1 خاتمه می‌یابد زیرا شواهد واقعی هنوز ثبت نشده‌اند.
